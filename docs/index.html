ChannelOps CLI

A personal, single-user command-line tool that automates routine work on a YouTube channel the operator owns: uploading and scheduling videos, editing titles/descriptions/tags, setting thumbnails, managing playlists and captions, moderating comments, and reading the channel's own private analytics.

What it is

ChannelOps CLI is a local program (the open-source yutu binary) run by one person on their own computer. It talks to the YouTube Data API v3 and the YouTube Analytics API v2 on behalf of exactly one Google account — the channel owner's. There is no web service, no sign-up, and no other users.

Single userOne operator, one channel, own credentials.
Local onlyRuns on the operator's machine; no hosted backend.
No data saleNo analytics of visitors, no advertising, no resale.

Scopes it asks for

  • youtube — upload and manage the channel's own videos, playlists, captions and comments.
  • yt-analytics.readonly — read the channel's own views, watch time and retention.
  • yt-analytics-monetary.readonly — read the channel's own revenue figures.
