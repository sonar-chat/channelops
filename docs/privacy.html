Privacy policy

ChannelOps CLI · last updated 14 November 2026

1. Who this covers

ChannelOps CLI is a personal command-line tool run by a single operator on their own computer, acting on the operator's own YouTube channel. It has no end users, no accounts and no hosted service. This policy explains what the tool does with Google account data.

2. What data is accessed

After the operator grants consent, the tool can access, through Google's APIs, only:

  • YouTube Data API v3 — the channel's own videos, playlists, captions, comments and channel metadata, with write access to publish and edit that content.
  • YouTube Analytics API v2 — the channel's own performance data: views, watch time, average view duration, traffic sources, and revenue figures.

Nothing outside the authorised channel is requested.

3. Where data goes

All API traffic goes directly from the operator's computer to Google's API endpoints. Requests and responses are not routed through any intermediary server. No copy of channel data, audience data or analytics is uploaded to any third party, sold, shared, or used to train models.

4. What is stored on disk

  • An OAuth token file (access and refresh token) in the operator's local profile directory, so the tool can run without repeated sign-in.
  • A client credential file issued by Google for this application.
  • Optional local exports (JSON/CSV) of analytics results the operator asked for.

These files stay on the operator's machine, are readable only by the operator's user account, and are never transmitted anywhere except to Google's OAuth token endpoint when refreshing access.

5. Retention and deletion

Local files persist until the operator deletes them. Revoking the application's access at myaccount.google.com/permissions immediately invalidates the stored token; deleting the local token file removes it from the machine. No server-side copy exists to delete, because there is no server.

6. Children

The tool is not directed at children and processes no personal data of viewers.
